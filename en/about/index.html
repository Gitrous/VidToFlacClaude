About VidToFLAC

Last updated: September 2026

VidToFLAC started from one specific, very repetitive problem: you import a video into DaVinci Resolve and there is no sound. The track shows up greyed out, or the clip lands silent, and nothing explains why. The cause is almost always the same — the audio codec is not licensed in that build of the program — and so is the fix: convert the audio to something the editor can actually read.

Online converters existed for that, but they all asked the same thing: upload your file to someone else's server, wait in a queue and trust that it gets deleted afterwards. For a 4 GB video that is slow, and for footage that is not yours it is simply not an option. VidToFLAC does the conversion without the file ever leaving your computer.

What it is

A free web tool that repackages video and converts audio inside your own browser. No accounts, no sign-up, no installation, no uploads. You open the page, drop the file in and download the result.

What it solves

The main case is the audio codec error in editing software: DaVinci Resolve, Adobe Premiere Pro and Avid Media Composer cannot always decode AAC, MP3 or AC-3, and the problem is especially pronounced in the free version of Resolve on Linux, where Blackmagic Design does not include those licences.

The tool copies the video without re-encoding it and converts only the audio to FLAC, which is lossless and natively supported. The picture is never touched, so it cannot degrade.

Beyond that, the formats page converts between commonly used containers and codecs — MP4, MKV, MOV, WebM, AVI, GIF, MP3, WAV, FLAC, M4A, OGG and Opus — for when the goal is publishing or archiving rather than editing.

How it works

The engine is FFmpeg compiled to WebAssembly (ffmpeg.wasm). When you open the page, the browser downloads that engine from a public CDN and runs it locally. From there, all the work happens on your machine:

  • The file is loaded into a virtual filesystem inside the browser tab.
  • The source codecs are probed to decide what can be copied and what must be re-encoded.
  • Whenever possible the video is copied as is (a remux) and only the audio is re-encoded.
  • The result comes back as a download, and the temporary files are cleared when you close the tab.

If the technical detail interests you, it is spelled out in the guide on using FFmpeg without installing anything.

Privacy

No file you convert is uploaded anywhere. That is not a policy promise: it follows from how the tool is built, because there is no conversion server to send them to. You can verify it by opening your browser's Network tab while converting, or by disconnecting from the internet once the page has loaded — the conversion still works.

What does involve processing personal data — the contact form and, where enabled, advertising — is set out in the privacy policy.

Limitations worth knowing

Running everything in the browser has advantages, but it also has a ceiling:

  • Processing uses the CPU only, with no GPU acceleration, so re-encoding long video is slower than desktop FFmpeg.
  • Available memory is capped by the browser's WebAssembly environment, not by your machine.
  • The web build does not include the full set of FFmpeg codecs.
  • Certain codec and container combinations force a re-encode rather than a copy.

They are described in full in the terms of service.
