What FFmpeg is and what it does

FFmpeg is an open-source program for processing audio and video. What makes it remarkable is its reach: it can read and write practically every video and audio format in existence, and operate on them — converting between formats, changing resolution, extracting audio, trimming clips, adding subtitles, altering bitrate.

Professional video editors, streaming services and broadcast systems use it internally. VLC relies on it to play practically any format. YouTube, Twitch and most video platforms use it to process what users upload.

In the terminal, a typical FFmpeg command looks like this:

ffmpeg -i input_video.mp4 -c:v libx264 -crf 18 -c:a flac output.mkv

Converts an MP4 to MKV with high-quality H.264 video and lossless FLAC audio.

The trouble with installing FFmpeg

Installing FFmpeg is an extra step many people either would rather not take or cannot:

  • Windows: you have to download the binary from a third-party site — the project offers no official installers — unzip it and add the path to your system PATH, a process that puts off non-technical users.
  • macOS: the easiest route is Homebrew (brew install ffmpeg), but first you have to install Homebrew.
  • Linux: the easiest of the three (apt install ffmpeg), but it still means using the terminal.
  • Shared or work computers: you may not have administrator rights to install software at all.

For someone who just needs to convert one video, installing FFmpeg is overkill. The answer is to use FFmpeg without installing it.

FFmpeg.wasm: FFmpeg in the browser

WebAssembly (Wasm) is a binary format modern browsers can run natively, at speeds close to native code. Developers have compiled FFmpeg to WebAssembly — the result is called FFmpeg.wasm.

That means FFmpeg can run inside Chrome, Firefox, Edge or Safari, directly on your device, with nothing to install. The advantages are considerable:

Nothing to install

There is nothing to install. The FFmpeg.wasm binary downloads automatically when you open the tool, and leaves no trace on your system.

100% private

The video file is processed on your device. It goes to no server. No uploads, no queues, no arbitrary size caps.

Works offline

Once the page has loaded and FFmpeg.wasm has downloaded, you can disconnect from the internet and conversion still works.

Cross-platform

It runs on Windows, macOS and Linux — on any device with a modern browser. It does not depend on the operating system.

The main limitation: FFmpeg.wasm can only use the CPU, not the GPU, so conversions that re-encode video are slower than native FFmpeg with hardware acceleration. For a remux — only the container changes, nothing is re-encoded — the difference is negligible.

When installing FFmpeg is worth it

FFmpeg.wasm is ideal for one-off conversions, but there are cases where installing native FFmpeg makes sense:

  • Processing hundreds of files: native FFmpeg with GPU acceleration is far faster for large batches. A bash loop converting 200 videos can take hours in FFmpeg.wasm and minutes with NVENC or VAAPI.
  • Very high-resolution video: at 4K or 8K, re-encoding in FFmpeg.wasm is slow because it cannot use the GPU. For 4K H.265 from a mirrorless camera, native FFmpeg with -hwaccel cuda or -hwaccel vaapi is 5 to 20 times faster.
  • Automated workflows: if you need conversion inside a script, a cron job or a CI/CD pipeline, FFmpeg in the terminal is the right tool.
  • Advanced FFmpeg options: complex video filters, dynamic bitrate control, multiple audio tracks, subtitles — FFmpeg.wasm supports a good deal, but not everything.
Rule of thumb: if you convert video occasionally and the file is under an hour at 1080p, use VidToFLAC (FFmpeg.wasm) — quicker to use, even if slightly slower to process. If you convert regularly or in batches, install FFmpeg.

Frequently asked questions

Is it possible to use FFmpeg without installing it?

Yes. FFmpeg compiled to WebAssembly (FFmpeg.wasm) runs directly in the browser with no installation at all. VidToFLAC uses FFmpeg.wasm to process video entirely locally — the file never leaves your device, and no server is involved.

Do "online FFmpeg" converters upload my files to a server?

Most do. Services advertising themselves as an "online FFmpeg converter" generally run FFmpeg on their own servers: you upload the file, they process it and return the result. VidToFLAC is different: it uses FFmpeg.wasm, which runs in your browser. The file never leaves your device.

Is FFmpeg.wasm as capable as regular FFmpeg?

For most everyday uses — converting formats, changing the audio codec, remuxing containers — yes. The difference is speed: FFmpeg.wasm uses the CPU only, whereas native FFmpeg can use the GPU to accelerate H.264/H.265 encoding. For simple operations like a remux or an audio swap the speed difference is small; for re-encoding 4K video, native FFmpeg with a GPU can be 10 to 20 times faster.

Can I convert video offline with VidToFLAC?

Yes, once the page has loaded. On first use the browser downloads FFmpeg.wasm from the CDN and caches it. After that you can disconnect from the internet and conversions keep working. The browser cache can be cleared, in which case you will need a connection for that first load again.

Which video formats does VidToFLAC support?

VidToFLAC accepts the common formats: MP4, MKV, MOV, AVI, WMV, WebM, FLV, M4V and more. The video can be H.264, H.265, VP9, AV1, MPEG-4, WMV, ProRes, DNxHD, MJPEG and others. If the format is exotic or very old, FFmpeg.wasm may not support it — in which case a native FFmpeg install is the alternative.
